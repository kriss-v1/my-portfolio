1. Project Executive Summary
The purpose of this document is to outline the structural, functional, and content requirements for a
personal software development portfolio website. This portfolio serves as an interactive showcase of
software development projects, technical skill sets, professional achievements, and contact information
for potential employers, clients, and collaborators.

2. Objectives & Target Audience
Primary Objectives
1.	Establish a strong professional online presence for software development opportunities.
2.	Demonstrate full-stack development capabilities through interactive project case studies.
3.	Provide quick access to GitHub repositories, and direct messaging.
Target Audience
•	Students
•	Companies
•	Individuals

3. Page Navigation Structure
The portfolio features: single-page layout & navigation:
 1. Header / Navigation Bar: links to sections (About, Projects, Skills, Contact), Theme
Toggle (Dark/Light mode).
 2. Hero Section: High-impact headline, professional tagline, primary Call-To-Action 
 3. About Me Section: Developer bio, education background, career objectives
 4. Featured Projects: Grid of key projects with interactive preview cards, tech tags, and case study modals.
 5. Technical Skills: Categorized technologies (Frontend, Backend, Database, Tools & DevOps).
 6. Experience &Education: Timeline of academic achievements, internships, and relevant roles.
 7. Contact & Footer: Interactive contact form, social media icons (GitHub, Twitter), copyright and automated notifications.


4. Technical Architecture
Recommended tech stack choices depending on development preference:
•	Frontend : HTML5 + CSS + JS
•	Backend : Node.js (Express.js)
•	Database: MySQL
